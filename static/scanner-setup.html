Расширение делает запросы к AnimeGo через ваш браузер и отправляет в каталог только найденные новые серии. Выберите браузер — Safari определится автоматически.

Установка в Safari 26

  1. Скачайте расширение Скачать ZIP Safari может установить скачанный ZIP напрямую. При желании распакуйте его и выберите папку.
  2. Включите функции для веб-разработчиков Откройте Safari → Settings → Advanced и включите Show features for web developers.
  3. Добавьте временное расширение Откройте Safari → Settings → Developer, нажмите Add Temporary Extension… и выберите скачанный ZIP или распакованную папку. Подтвердите системный запрос Safari, если он появится.
  4. Разрешите доступ к Anime Catalog В Safari разрешите расширению website access для текущего Anime Catalog. Доступ к animego.me сканер запросит отдельно при первом Scan — нажмите во вкладке расширения Разрешить AnimeGo и подтвердите Safari.
  5. Обновите каталог Вернитесь в Anime Catalog и перезагрузите страницу (⌘R). Кнопки Scan и Full Scan станут активны.
Временная установка удаляется через 24 часа или при выходе из Safari. После этого повторно добавьте ZIP или папку через Add Temporary Extension….

Установка в Chrome

  1. Скачайте расширение Скачать ZIP
  2. Распакуйте ZIP Оставьте папку animego-scanner в удобном постоянном месте.
  3. Откройте расширения Chrome
    chrome://extensions
  4. Включите «Режим разработчика» Нажмите «Загрузить распакованное» и выберите распакованную папку.
  5. Вернитесь в каталог Обновите страницу. При первом Scan подтвердите узкий доступ к animego.me во вкладке сканера; серверное задание создастся только после разрешения.
Расширение запрашивает доступ только к animego.me, локальному dev и production Anime Catalog. Оно не читает историю браузера и не скачивает видео.
